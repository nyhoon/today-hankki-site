# 알뜰한끼 웹사이트

정적 서비스 소개 사이트입니다. Android와 iPhone 앱은 Google Play와 App Store에서 공개 중이며, 검색 메타데이터는 공개 앱 기능과 일치시킵니다. `privacy.html`과 `terms.html`은 **가입 동의용 최종 법률 문서가 아닙니다.**

링크 공유용 썸네일은 `assets/og-today-hankki.png`이며 `index.html`의 `og:image`와 `twitter:image`에서 사용합니다. Play 링크 자체의 미리보기는 메신저가 Google Play 페이지를 스크랩하는 정책/캐시에 따라 달라질 수 있으므로, 이미지 미리보기가 필요한 홍보 글에는 소개 페이지 `https://nyhoon.github.io/today-hankki-site/` 링크를 사용합니다. 소개 페이지의 설치 버튼은 Google Play와 App Store로 연결됩니다.

개인정보 및 이용 안내는 실제 데이터 처리·위탁·국외 이전·보유 기간·법적 운영자 정보와 맞는지 계속 확인하고, Supabase `policy_documents`의 버전과 일치시킵니다. 웹사이트 URL은 별도의 HTTPS 주소로 사용하고, Supabase 모바일 인증 복귀 주소는 앱 딥링크를 사용합니다.
