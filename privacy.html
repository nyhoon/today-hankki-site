2. 처리 항목과 목적

이메일 가입은 입력한 이메일 주소, 인증정보, 닉네임, 만 14세 이상 확인 여부와 약관 동의 시각을 계정 운영에 사용합니다. 이메일 소유 여부는 가입 때 확인하지 않습니다. Google·카카오 로그인은 제공자가 전달하고 이용자가 동의한 계정 식별자와 프로필 정보·이메일(제공되는 경우)을 인증에 사용합니다. 이메일 계정과 소셜 계정은 이메일 주소만으로 자동 연결하지 않습니다.

키친 기능은 키친 이름, 구성원·권한·초대 기록, 재료 이름·수량·보관 위치·표시 날짜·바코드, 장보기 목록을 공유 재고와 추천 기능에 사용합니다. 커뮤니티 기능은 사용자가 작성한 레시피·사진·후기·별점·좋아요·팔로우·신고와 검토 처리 기록을 서비스 제공 및 운영에 사용합니다.

서비스 보호와 문의 대응을 위해 가입·로그인, 키친 생성·참여, 재료 등록·수정·삭제, 장보기 목록 변경, 사용자 레시피 작성·수정·검토 요청, 후기·신고·좋아요·팔로우와 같은 주요 행동의 종류와 시각을 계정과 연결해 기록합니다. 재료 또는 장보기 항목을 등록·수정·삭제하면 활동 상세에 항목 이름, 동작 종류와 허용된 필드의 변경 전·후 값도 기록할 수 있습니다. 재료 허용 필드는 이름·수량·단위·보관 위치·표시 날짜 종류·표시 날짜·개봉 날짜·확인 상태이며, 장보기 허용 필드는 이름·수량·단위·보관 위치·체크 상태입니다. 바코드, 레시피·후기·신고 본문, 사진, 전체 데이터 행과 화면 열람 기록은 활동 상세에 복사하지 않습니다. 이 상세는 최근 90일 동안 운영 권한이 있는 운영자만 사용자 계정 상세에서 확인할 수 있습니다.

선택적으로 앱 설정에서 ‘계정별 재료 검색 이력’을 켜면 사용자가 검색을 제출한 시점에 표준 재료 코드, 검색 화면 종류와 시각을 계정과 연결해 운영 화면에 최대 90일 표시합니다. 재료 표준명과 별칭으로 확인되는 검색만 기록하며, 자유 입력 원문, 일부 입력, 수량, 키 입력 과정은 저장하지 않습니다. 이 기능은 기본 꺼짐이며 Firebase 분석·오류 보고와 별개로 동의할 수 있습니다. 언제든 앱 설정에서 끄면 기존 계정 연결 검색 이력을 삭제합니다.

쿠팡 검색 버튼으로 외부 브라우저를 실제 연 경우, 로그인 및 최신 이용약관·개인정보처리방침 동의를 확인한 뒤 Supabase에 한국 날짜·진입 경로별 횟수를 저장합니다. 표준 재료 코드가 연결된 항목은 코드별 횟수도 집계하며, 확인되지 않은 항목은 전체 횟수에만 포함합니다. 앱이 쿠팡 링크에 넣어 전달한 검색어는 공백을 정리하고 소문자화한 뒤 최대 80자로, 계정 ID·이메일·기기 정보 없이 날짜·진입 경로·검색어별 익명 합계에 최대 90일 저장합니다. 이메일·웹 주소·전화번호처럼 보이는 값은 검색어 통계에서 제외하며, 민감한 정보는 검색어에 넣지 마세요. 최신 개인정보처리방침에 동의한 경우에만 기록하고 Firebase 분석 동의와는 별개입니다. 쿠팡 화면이 열린 뒤 이용자가 그곳에서 직접 입력하거나 바꾼 검색어는 앱에서 읽거나 집계하지 않습니다. 외부 브라우저 열기 횟수는 쿠팡의 상품 검색 성공·구매·수수료를 뜻하지 않습니다. 선택적으로 ‘사용 분석 및 오류 보고’를 켠 경우에는 Firebase Analytics·Crashlytics가 앱 화면·기능 이벤트, 앱·기기 정보와 오류 정보를 처리할 수 있습니다. Android에서 Firebase Analytics를 허용한 경우 앱 삭제 이벤트(app_remove)가 Firebase/Google Analytics 보고서에 집계될 수 있으며 오늘한끼 운영 DB에 사용자별로 저장하지 않습니다. Firebase Analytics 이벤트에는 검색어 원문이 포함되지 않습니다.

3. 사진, 기기 권한과 알림

카메라와 사용자가 선택한 사진은 기기에서 문자 인식에 사용할 수 있습니다. 이 인식용 원본은 서버로 전송하지 않습니다. 사용자가 등록한 프로필 사진과 커뮤니티 레시피 사진은 Supabase 저장소에 업로드됩니다. 프로필 사진은 같은 키친 구성원에게, 승인된 커뮤니티 레시피 사진은 로그인한 서비스 이용자에게 표시됩니다.

푸시 알림을 켠 경우 기기 푸시 토큰, 플랫폼(Android/iOS), 알림 종류별 설정과 활성 상태를 처리하고 Firebase Cloud Messaging으로 알림을 전달합니다. 알림에 재료명·레시피명·장보기 항목명이 포함될 수 있으므로 잠금화면에 표시될 수 있습니다. 알림을 끄거나 로그아웃하면 기기 토큰을 비활성화하며, 탈퇴하면 계정과 연결된 토큰을 삭제합니다. FCM 전송에서 토큰이 무효라고 확인되면 해당 토큰을 서버에서 삭제하고 날짜·플랫폼별 건수만 집계합니다. 토큰 만료·갱신·재설치·FCM 등록 해제도 같은 신호를 만들 수 있으므로 FCM 토큰 무효화는 앱 삭제 확정이 아닙니다.

4. 보유 기간과 삭제

계정 및 프로필 정보는 탈퇴 절차에 따라 삭제합니다. 주요 행동 로그와 허용된 재료·장보기 변경 상세, 선택적 계정별 재료 검색 이력은 생성 시점부터 90일 동안 보유한 뒤 매일 정리하며, 계정별 재료 검색 이력을 끄면 해당 계정 검색 이력을 바로 삭제하고 탈퇴 시에도 계정 연결 로그를 삭제합니다. 탈퇴 완료 건수와 무효 FCM 토큰 건수는 개인 식별자·토큰 없이 한국 날짜·이벤트 종류·플랫폼별 합계로 최대 365일 보유한 뒤 매일 정리합니다. 앱 삭제를 개인별로 판정하거나 계정에 연결하지 않습니다. 쿠팡 재료·진입 경로별 외부 열기 합계는 개인을 식별할 수 없는 한국 날짜별 기록으로 최대 365일, 앱에서 쿠팡 링크에 전달한 검색어별 익명 합계는 최대 90일 보유하며 매일 오전 1시(한국 시간) 만료 기록을 삭제합니다. 키친 데이터는 키친이 유지되는 동안 공유 구성원에게 제공될 수 있습니다. 공유 재고 변경 이력은 키친 운영과 무결성을 위해 재고 데이터와 함께 유지될 수 있습니다. 푸시 토큰은 더 이상 필요하지 않을 때 비활성화·삭제하고, 법령상 보존 의무가 있는 정보는 해당 기간에 한해 분리 보관합니다. 백업은 백업 보존 주기에 따라 제거합니다.

5. 처리 위탁 및 국외 처리

계정 인증·데이터 저장·서버 기능에 Supabase를 사용하며 주 데이터베이스 지역은 일본 도쿄(ap-northeast-1)입니다. AI 추천을 이용하면 입력한 선호 문구와 레시피 후보 정보가 OpenAI API로 전송됩니다. 사용 분석·오류 보고 또는 푸시 기능을 이용하면 Google LLC의 Firebase Analytics, Firebase Crashlytics 또는 Firebase Cloud Messaging이 관련 정보를 처리할 수 있습니다. 계정별 검색 이력과 운영자 전용 활동 상세는 Supabase 데이터베이스에 저장되며 운영 권한이 확인된 운영자만 사용자 상세에서 볼 수 있습니다. Android 앱 삭제 이벤트는 Firebase Analytics 보고서에서 확인하고, 계정 탈퇴 및 무효 FCM 토큰 건수는 개인 식별자 없는 집계로 Supabase에 저장합니다. 쿠팡 외부 브라우저 열기 및 앱에서 전달한 검색어 이벤트는 최신 정책에 동의한 로그인 사용자의 경우 Firebase 분석 동의와 별개로 날짜·경로·검색어별 익명 합계를 Supabase에 저장합니다. Firebase Analytics 이벤트에는 검색어 원문이 포함되지 않습니다. 각 제공자의 처리 위치와 보유 기간은 서비스 설정 및 정책에 따르며 국외에서 처리될 수 있습니다.

6. 이용자 권리와 보호

이용자는 앱에서 프로필을 수정하거나 계정을 삭제할 수 있고, 앱 설정에서 선택적 계정별 재료 검색 이력을 끄거나 위 문의 주소로 열람·정정·삭제·처리정지를 요청할 수 있습니다. 다른 키친 구성원의 권리 또는 법령상 보존 의무에 따라 일부 요청이 제한될 수 있으며 그 사유를 안내합니다. 계정 인증, 키친별 접근 권한, 비공개 파일 접근 정책을 적용합니다.

7. 변경 안내

수집 항목, 처리 목적, 위탁 또는 국외 처리 내용이 달라지면 방침을 갱신하고 시행일을 알립니다. 새 동의가 필요한 변경은 앱에서 별도로 동의를 받습니다.
