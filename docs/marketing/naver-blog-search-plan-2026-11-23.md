## 진단

- 공개 글은 3개. 수정 전 목록의 누적 조회수는 영수증 글 5, 장보기 글 3, 재료 등록 글 1. 운영자 확인 방문이 섞일 수 있으며 이 숫자를 신규 고객 수로 해석하지 않는다.
- 글 3개 모두 전체공개·검색허용·외부 공유 허용이 이미 켜져 있었다. 검색 설정을 켠 덕분에 노출된 것처럼 보고하지 않는다.
- 네이버에서 기존 제목 `"마트 장보기 체크리스트 3가지"`를 검색했을 때 실제 장보기 게시물 URL이 결과에 표시됨을 확인. 블로그 전체가 미수집/검색 제한 상태라고 단정할 근거 없음. 일반적인 키워드의 순위·월간 검색량은 미확인.
- 영수증 글은 실제 앱 화면 2개, 장보기 글은 이미지 1개였지만 재료 등록 글에는 이미지가 0개였다.
- 글별 유입경로 화면을 열었으나 처음 일간 조회는 오늘 0, 월간 기본값은 글 발행 전인 10월이었다. 이를 11월 전체 검색 유입 0이라는 근거로 사용하지 않는다.

## 앞으로의 편집 전략

핵심은 설치 전에 읽어도 해결할 수 있는 실용 정보 + 앱에서 실제로 하는 모습이다. ‘우리 앱에 이런 기능이 있어요’만 열거하지 않는다.

### 운영할 검색 주제

1. **입력 부담:** 재료 등록이 귀찮은 사용자 → 위 개선 글을 중심 문서로 유지.
2. **일괄 등록:** 영수증 식재료 등록 → 기존 영수증 글로 집중. 인식 실패 질문도 이 문서에 통합해 유사 글 경쟁을 피함.
3. **장보기 실수:** 중복 구매/장보기 메모 → 기존 장보기 글에서 실제 양식 제공.
4. **홈 화면 확인:** ‘아이폰 냉장고 위젯 추가’, ‘안드로이드 식재료 위젯’ → 각 OS의 실제 화면을 확보한 뒤 별도 문서. 지원 동작을 실제 앱에서 확인해야 발행.
5. **등록 후 효용:** ‘냉장고 재료로 레시피 찾기’ → 실제 등록 재료와 실제 검색 결과를 보여주는 사례. 결과나 조리 경험을 꾸미지 않음.
6. **절약 기록:** ‘식재료 다 먹고 절약 기록’ → 구매가 3,000원 × 앱 가정 20% = 600원 등 계산과 한계를 함께 설명. 실제 절약·현금 보상 보장으로 포장하지 않음.

월간 검색량과 경쟁 강도는 미확인이다. 위 목록은 검색 의도에 기반한 후보이지, 검증된 고검색량 키워드 목록이 아니다.
